# 🐱 하치와레 놀이터

치이카와의 **하치와레**를 쓰다듬고 볼을 콕콕 건드리며 노는 귀여운 반응형 웹앱이에요.
미니게임도 두 개 들어있어요. 서버 없이 브라우저에서 바로 돌아가는 정적 웹앱(GitHub Pages)입니다.

## 화면 구성

- **놀아주기** — 하치와레와 상호작용하고 기분을 관리하는 메인 화면
- **게임** — 게임 목록에서 하치와레 잡기 또는 카드 짝맞추기를 선택
- **테마** — 우측 상단 달/해 버튼으로 전환하며 선택은 브라우저에 저장

## 놀거리

- **🐱 놀아주기** — 하치와레를 콕 누르면 표정이 바뀌고 하트가 뿅뿅! 오래 안 놀아주면 삐져요.
  - 양 볼을 잡고 바깥으로 끌면 얼굴과 볼터치가 늘어났다가 놓을 때 통통 튕기며 돌아와요.
  - 쓰다듬기에는 편안한 표정, 간식에는 신난 표정, 랜덤뽑기에는 놀란 뒤 기뻐하는 반응이 나와요.
  - 쓰다듬기 / 간식주기 / 랜덤뽑기 버튼
  - 기분 게이지(mood)와 함께한 콕콕 횟수 저장
- **🕳️ 하치와레 잡기** — 튀어나오는 하치와레를 콕! 폭탄🧨은 피하는 30초 두더지잡기. 최고점수 저장.
- **🃏 카드 짝맞추기** — 같은 그림 카드를 찾는 메모리 게임. 최소 뒤집기 기록 저장.

## 특징

- 📱 **반응형 UI/UX** — 모바일과 PC 모두 상단의 두 탭으로 이동하고 터치와 마우스를 지원
- 💾 **데이터 유지** — 기분·콕콕 횟수·최고점수·선택한 테마를 `localStorage`에 저장 (같은 브라우저에서 계속 유지)
- 🔔 **효과음** — 파일 없이 WebAudio로 생성 (헤더의 종 버튼으로 on/off)
- ⚙️ 외부 라이브러리 없음. HTML/CSS/JS 순수 구현.

## 저작권 안내

하치와레는 치이카와의 캐릭터입니다. 이 팬 프로젝트는 공식 제작물 또는 공식 제휴 서비스가 아닙니다. 공개 배포나 상업적 사용 전에는 권리자의 이용 조건을 확인하세요.

## 로컬에서 보기

그냥 `index.html`을 브라우저로 열면 됩니다. (또는 `python3 -m http.server` 후 접속)

## GitHub Pages 배포

레포 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `/ (root)`** 로 설정하면
`https://kisnoohc02.github.io/chiikawa/` 에서 열려요.

## 저장 데이터 초기화

브라우저 콘솔에서: `localStorage.removeItem("monggle_v1"); localStorage.removeItem("hachiware_theme")`

## 파일 구성

- `index.html` — 구조 / 하치와레 SVG / 탭
- `favicon.svg` — 브라우저 탭에 표시되는 하치와레 얼굴 아이콘
- `style.css` — 반응형 스타일 · 라이트/다크 테마 · 애니메이션
- `app.js` — 인터랙션 · 미니게임 · 저장 로직
