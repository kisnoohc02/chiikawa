# 🐱 하치와레 놀이터

치이카와의 **하치와레**를 쓰다듬고 볼을 콕콕 건드리며 노는 귀여운 반응형 웹앱이에요.
미니게임 다섯 개(잡기·카드·오목·체스·별사탕 언덕)가 들어있어요. 서버 없이 브라우저에서 바로 돌아가는 정적 웹앱(GitHub Pages)입니다.

## 화면 구성

- **놀아주기** — 캐릭터를 직접 누르거나 볼을 당길 수 있습니다. 간식은 동전으로 바로 사서 줄 수 있습니다.
- **게임** — 잡기·카드·오목·체스는 Lv1~Lv10을 선택합니다. 별사탕 언덕은 레벨 없이 끝없이 달리며 점수에 비례해 동전을 받습니다.
- **아이템** — 뽑기 선물을 보관하고 장신구·배경·색 테마를 장착하거나, 보관한 음식을 먹일 수 있습니다.
- **다크 모드** — 우측 상단 버튼으로 바꿀 수 있으며 아이템 색 테마와 별개로 저장됩니다.

## 재화와 보상

처음에는 30동전을 갖고 시작합니다. 기존 저장 데이터에도 처음 업데이트할 때 30동전이 지급됩니다.

| 게임 | Lv1~Lv10 난이도 | 클리어 조건 | 보상 |
| --- | --- | --- | --- |
| 하치와레 잡기 | 등장 속도·폭탄 확률·목표 점수가 증가 | 30초 내 목표 점수 | Lv와 30초 기준 |
| 카드 짝맞추기 | 카드 쌍 증가·시간 제한 감소 | 제한 시간과 뒤집기 횟수 안에 모든 짝 맞추기 | Lv와 실제 플레이 시간 기준 |
| 오목 | 봇 탐색 깊이·후보 폭 증가 | 먼저 5목 연결 | Lv와 플레이 시간 기준 |
| 체스 | 봇 탐색 깊이·시간 증가 | 봇 체크메이트 또는 기권 없는 승리 | Lv와 플레이 시간 기준 |
| 별사탕 언덕 | 레벨 없음, 거리가 늘수록 속도 증가 | 돌·틈에 부딪힐 때까지 계속 달리기 | 최종 점수 10점당 동전 1개 |

보상은 `Lv × (8 + 0.45 × 플레이 초)`를 반올림하며, 초는 20~600초 범위로 제한합니다. 보드게임은 빠른 반복 획득을 막기 위해 수에 따른 최소 시간을 적용합니다. 기존 네 게임에서 패배·무승부·중도 종료는 보상이 없습니다. 달리기는 장애물 충돌로 끝난 판에만 보상이 지급되며 화면을 벗어나거나 일시정지한 상태에서는 지급되지 않습니다. 기존 산책/모험/도전 기록은 각각 Lv2/Lv5/Lv8로 이전합니다.

오목은 15×15판에서 흑돌이 가운데 첫 수를 두며, 흑의 3-3·4-4·장목을 막는 렌주식 간편 규칙을 사용합니다. 정확한 5목은 흑의 승리, 백은 장목도 승리입니다. 복잡한 대회 오프닝 교환·제안 절차와 드문 중첩 금수의 완전한 재귀 판정은 생략했습니다. 체스는 백이 선공이며 합법 수, 체크·캐슬링·앙파상·퀸 자동 승격, 반복·50수 규칙의 무승부를 지원합니다. 보드게임에는 한 수 무르기, 힌트, 마지막 수 표시가 있고 체스판은 뒤집을 수 있습니다. 봇은 브라우저에서 휴리스틱과 제한 시간 탐색으로 동작하며, 높은 레벨도 모든 상대를 이기는 수준을 보증하지는 않습니다.

각 게임 화면의 **놀이 방법 보기** 또는 **규칙·특수 수 보기**를 펼치면 해당 게임의 간단한 룰북이 나옵니다. 오목판과 체스판, 카드와 게임 선택 화면은 하치와레의 하늘색·크림색·분홍색 팔레트로 꾸몄고 다크 모드도 함께 적용합니다.

간식 가격은 주먹밥 10동전, 팬케이크 20동전, 딸기 35동전입니다. 랜덤 선물 뽑기는 50동전이며 장신구, 배경, 색 테마, 음식, 소장품 가운데 하나를 받습니다. 중복 아이템도 수량으로 보관합니다.

별사탕 언덕은 자동으로 전진하며 화면 터치, 점프 버튼, 스페이스/↑/W 키로 뛰고 공중에서 한 번 더 뛸 수 있습니다. 일시정지와 이어하기를 지원하며 최고 점수·최고 별 개수·누적 점수를 기록합니다. 별사탕 하나는 35점입니다. 이 게임의 그림과 이름은 독자적인 구성입니다.

## 상호작용

- 캐릭터를 누르거나 볼을 잡아 바깥쪽으로 드래그할 수 있습니다.
- 뽑기로 받은 장신구는 캐릭터 그림에, 배경은 놀이터에, 색 테마는 화면 전체에 반영됩니다.
- 뽑기로 받은 음식은 아이템 탭에서 수량을 소비하여 먹일 수 있습니다.

## 특징

- 📱 **반응형 UI/UX** — 모바일과 PC 모두 상단의 세 탭으로 이동하고 터치와 마우스를 지원
- 💾 **데이터 유지** — 기분·콕콕 횟수·동전·아이템·장착 상태·Lv별 기록·선택한 테마를 `localStorage`에 저장 (같은 브라우저에서 계속 유지)
- 🔔 **효과음** — 파일 없이 WebAudio로 생성 (헤더의 종 버튼으로 on/off)
- ⚙️ 외부 라이브러리 없음. HTML/CSS/JS 순수 구현.
