# 하치와레의 하루

## 놀아주기

하치와레를 누르거나 볼을 당기면 표정과 기분이 바뀝니다. 게임에서 얻은 동전으로 간식을 주거나 랜덤 선물을 뽑을 수 있습니다.

## 게임

- **하치와레 잡기:** 30초 안에 목표 점수를 달성합니다. 폭탄을 누르면 점수가 줄어듭니다.
- **카드 짝맞추기:** 제한 시간과 뒤집기 횟수 안에 모든 짝을 찾습니다.
- **오목:** 봇과 대결합니다. 흑돌의 3-3·4-4·장목 금수를 적용하며, 복잡한 대회 오프닝 절차는 생략합니다.
- **체스:** 봇과 대결합니다. 체크, 캐슬링, 앙파상, 자동 퀸 승격을 지원합니다.
- **별사탕 언덕:** 자동으로 달리며 점프해 장애물을 넘고 별사탕을 모읍니다. 레벨 없이 점수 10점당 동전 1개를 받습니다.

앞의 네 게임은 Lv1~Lv10을 선택하며, 난이도와 플레이 시간에 따라 보상을 받습니다. 각 게임의 최고 기록과 누적 기록이 저장됩니다. 게임 안의 **놀이 방법 보기**에서 규칙을 확인할 수 있습니다.

## 아이템

장신구 16종, 배경 14종, 색 테마 10종, 음식 12종, 소장품 11종을 모을 수 있습니다. 장신구·배경·테마를 장착하면 화면에 반영되고, 음식은 하치와레에게 줄 수 있습니다. 도감에서 전체 또는 보유 아이템을 볼 수 있습니다.

## 데이터와 화면 설정

아이템 화면의 **데이터 관리**에서 현재 동전, 아이템, 장착 상태, 게임 기록과 화면 설정을 JSON 파일로 내보내거나 불러올 수 있습니다. 불러오기는 현재 데이터를 교체합니다. 상단 버튼으로 효과음과 다크 모드를 바꿀 수 있습니다.
