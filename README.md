# 🐰 몽글이 놀이터

몽글몽글 오리지널 마스코트 **몽글이**를 쓰다듬고 볼을 콕콕 건드리며 노는 귀여운 반응형 웹앱이에요.
미니게임도 두 개 들어있어요. 서버 없이 브라우저에서 바로 돌아가는 정적 웹앱(GitHub Pages)입니다.

## 놀거리

- **🐰 놀아주기** — 마스코트를 콕 누르면 표정이 바뀌고 하트가 뿅뿅! 오래 안 놀아주면 삐져요.
  - 쓰다듬기 / 간식주기 / 랜덤뽑기 버튼
  - 기분 게이지(mood)와 함께한 콕콕 횟수 저장
- **🕳️ 몽글이 잡기** — 튀어나오는 몽글이를 콕! 폭탄🧨은 피하는 30초 두더지잡기. 최고점수 저장.
- **🃏 카드 짝맞추기** — 같은 그림 카드를 찾는 메모리 게임. 최소 뒤집기 기록 저장.

## 특징

- 📱 **반응형 UI/UX** — 모바일에선 하단 탭바 + 터치, PC/태블릿에선 상단 탭 + 마우스로 자연스럽게 작동
- 💾 **데이터 유지** — 기분·콕콕 횟수·최고점수를 `localStorage`에 저장 (같은 브라우저에서 계속 유지)
- 🔔 **효과음** — 파일 없이 WebAudio로 생성 (헤더의 종 버튼으로 on/off)
- ⚙️ 외부 라이브러리 없음. HTML/CSS/JS 순수 구현.

## 저작권 안내

캐릭터는 특정 저작물을 복제하지 않은 **오리지널 마스코트(몽글이)** 입니다.

## 로컬에서 보기

그냥 `index.html`을 브라우저로 열면 됩니다. (또는 `python3 -m http.server` 후 접속)

## GitHub Pages 배포

레포 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `/ (root)`** 로 설정하면
`https://kisnoohc02.github.io/chiikawa/` 에서 열려요.

## 저장 데이터 초기화

브라우저 콘솔에서: `localStorage.removeItem("monggle_v1")`

## 파일 구성

- `index.html` — 구조 / 마스코트 SVG / 탭
- `style.css` — 반응형 스타일 · 애니메이션
- `app.js` — 인터랙션 · 미니게임 · 저장 로직
